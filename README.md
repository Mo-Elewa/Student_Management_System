# Student Management System

## About the Project
A simple Student Management System built using Python.

This project helps manage student records through a simple menu-driven interface.

## Features
- Add new students.
- Search for students.
- Update student information.
- Delete student records.
- Display student information.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Python Modules

## Project Structure
The project is organized into multiple Python files to make the code easier to read and maintain.

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Run `main.py` using Python.
